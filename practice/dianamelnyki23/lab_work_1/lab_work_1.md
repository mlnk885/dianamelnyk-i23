# Практична робота №1

## Варіант 7 — Спортзал (фітнес-клуб)

Для практичної роботи створено базу даних SQLite з таблицею `memberships`, яка містить інформацію про абонементи фітнес-клубу.

### Обґрунтування типів даних

**id — INTEGER PRIMARY KEY**

Для стовпця `id` обрано тип `INTEGER PRIMARY KEY`, оскільки він використовується як унікальний ідентифікатор кожного абонемента. Значення є цілими числами. `PRIMARY KEY` забезпечує унікальність записів.

**type — TEXT**

Для стовпця `type` використано `TEXT`, оскільки він містить текстові назви типів абонементів: «Разовий», «Тижневий», «Місячний», «Квартальний», «Піврічний» та «Річний».

**duration_days — INTEGER**

Для стовпця `duration_days` обрано `INTEGER`, оскільки тривалість абонемента задається цілим числом днів. Наприклад, місячний абонемент має тривалість 30 днів.

**price — REAL**

Для стовпця `price` використано `REAL`, оскільки ціна може містити дробову частину. Цей тип підходить для зберігання числових значень вартості абонементів.

### Висновок

Для таблиці `memberships` обрано типи даних відповідно до характеру інформації. `INTEGER` використовується для цілих чисел, `TEXT` — для текстових значень, а `REAL` — для числових значень, які можуть мати дробову частину. Такий вибір відповідає поняттю type affinity у SQLite.
