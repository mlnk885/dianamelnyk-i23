# Практична робота №2

## Виконання SELECT-запитів у SQLite

### Мета роботи

Навчитися виконувати SQL-запити для вибірки даних із таблиці, використовувати умови фільтрації, обмеження кількості результатів, перевірку значень NULL та комбінування умов.

### Хід виконання роботи

Під час практичної роботи було використано базу даних фітнес-клубу, створену під час практичної роботи №1.

Було виконано п'ять завдань із використанням оператора SELECT. Спочатку було виведено всі записи з таблиці абонементів. Далі виконано фільтрацію за тривалістю абонемента, обмежено кількість отриманих записів до трьох та перевірено роботу умов IS NULL і IS NOT NULL.

Також було виконано запит із двома одночасними умовами: тривалість абонемента не менше 30 днів та ціна не більше 5200 грн.

### Контрольні питання

#### 1. Чому умова `WHERE price = NULL` не повертає результатів? Як правильно перевіряти NULL?

NULL означає відсутність або невідоме значення, тому його не можна порівнювати зі звичайним оператором дорівнює. Умова `price = NULL` не працює для перевірки відсутності значення.

Для перевірки NULL використовується оператор IS NULL. Щоб знайти записи, у яких значення не є NULL, використовується оператор IS NOT NULL.

#### 2. Чим відрізняються WHERE і HAVING?

WHERE використовується для фільтрації окремих рядків до виконання групування. HAVING використовується для фільтрації вже згрупованих результатів, зазвичай разом із GROUP BY та агрегатними функціями.

Отже, WHERE працює з окремими записами, а HAVING — із групами записів після їх групування.

#### 3. Коли та навіщо уникати SELECT *?

SELECT * виводить усі стовпці таблиці. Його варто уникати, коли потрібні лише конкретні поля, оскільки вибір усіх стовпців може отримувати зайві дані, збільшувати обсяг результату та ускладнювати роботу із запитом.

Краще явно вказувати назви потрібних стовпців. Це робить SQL-запити зрозумілішими, точнішими та зручнішими для подальшої підтримки.

### Висновок
